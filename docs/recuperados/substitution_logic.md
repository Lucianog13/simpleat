# CopingChef: Argentine Survival Logic

Strategy to minimize user frustration from missing ingredients by providing "Croto pero rico" (Cheap but tasty) solutions.

## Contextual Hacks
The system generates tips based on existing ingredients rather than randomness:
- **Alitas de Pollo:** Tip for a "Crunchy" coating using polenta or fine breadcrumbs.
- **Lomo/Bife:** Hack for a "Perfect Sear" (very hot pan, no salt initially).
- **Cerdo:** "Acid Marination" hack using lemon to tenderize fibers.
- **Zapallito:** "Zero Waste" hack (using the centers in the onion sauté).

## Static Substitutions (Alacena Survival)
- **Parmesano:** Replacement with Pan Rallado + Provenzal (toasted).
- **Crema de Leche:** Replacement with Leche + Manteca (controlled heat).
- **Vino Blanco:** Replacement with Cider or diluted Vinegar + Sugar (in specific contexts).

## Persona Tone
- **Authority:** Master Chef Senior.
- **Vibe:** "I've been there, I know how to fix it with what's in your drawer."
- **Direct Order:** Using imperative verbs to reduce cognitive load.
