# SimpleEat Project Overview

SimpleEat is a "Digital Twin" of the Argentine pantry, designed to provide "Invisible Technology" and "Zero Friction" culinary guidance.

## Core Principles
- **Invisible Technology:** The interface is minimal, with a natural language Omnibar that handles complex, multi-term ingredient inputs.
- **Zero Friction:** The system provides immediate, actionable solutions based on what the user actually has.
- **Master Chef Senior Persona:** Instructions are professional, technically precise (using verbs like Sellar, Picar, Emulsionar), and authoritative.
- **Nodo Paraná Identity:** Specialization in regional Entre Ríos ingredients (river fish, local vegetables) and seasonality.

## Major Components
- **CopingChef Logic:** Handles survival substitutions and contextual "hacks".
- **Argentine Encyclopedia:** Comprehensive map of proteins, vegetables, and spices.
- **NLP Sentiment & Parsing:** High-precision extraction of ingredients and quantities.
- **Master Chef Protocol:** Logic that validates recipes for speed (Fast) and health (Mandate).
